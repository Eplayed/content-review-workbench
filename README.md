# content-review-workbench · AI 内容审稿工作台

> AI 负责写，你负责审——带人工审稿闭环的轻量自媒体内容产线。

市面上的同类工具分两类：一类在卷「一键分发 20+ 平台」的全自动矩阵（踩平台红线），另一类是纯生成流水线（没有审稿、没有复盘）。本产品反其道而行：**把「人机协同审稿闭环」做成一等公民**，符合平台 AI 内容整顿后的合规趋势。

## 定位

自托管的轻量内容产线：

```
素材库 → AI 生成初稿 → 人工审稿（三态流转）→ 导出发布 → 数据回填 → 周报复盘
```

目标用户：一人自媒体、小商家、代运营者。

## 核心特性

- **三态审稿流**：待审（pending）→ 已审（reviewed）→ 已发（published），全勾 checklist 才能过审
- **AI 腔检测**：对比修辞滥用、教科书式小标题、车轱辘词密度等规则化检测，红黄标出、一键定位（纯函数实现，带单元测试）
- **素材库**：粘贴文本 / CSV 导入，入库即用
- **AI 生成**：OpenAI 兼容接口直连（baseUrl / model / apiKey 可配置），预留 Dify workflow 适配器
- **排版导出**：Markdown → 公众号内联样式 HTML
- **数据回填与周报**：阅读/点赞/收藏/分享/净增粉丝多次回填，按周聚合产量与中位数表现

## 路线图

- [ ] **M1 审稿闭环**：素材导入、AI 生成、三态流转、AI 腔检测、审稿 checklist
- [ ] **M2 排版与回填**：公众号 HTML 导出、发布登记、数据回填、简版周报
- [ ] **M3 配置与打磨**：AI 设置页、检测规则开关、JSON 备份/恢复

## 技术栈

Node.js 20 · Express · better-sqlite3（SQLite 单文件）· 原生 HTML/CSS/JS（无构建步骤）· Docker

## 快速开始

> 项目开发中，首个可用版本将随 M1 里程碑发布。

```bash
# 方式一：Docker（推荐）
docker compose up -d

# 方式二：本地运行
node server.js
```

## 合规声明

本工具**不包含任何平台的自动登录、自动发布、批量定时发布功能**。发布动作由人工完成——这是特性，不是缺陷。
